# Vendored skills

The `omnibenchmark-*` skills are copied from
[omnibenchmark/skills](https://github.com/omnibenchmark/skills) at commit
`bcb034939d94dc95ccfcd9a0046b66d9f722994a` (MIT, see `LICENSE-omnibenchmark`).
They are committed here so cloud sessions on this repo load them without the
`/plugin` command. To update, copy `skills/*` from a newer checkout of that repo.
